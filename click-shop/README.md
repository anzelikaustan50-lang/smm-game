# Click Med: интернет-магазин

Статический сайт без сборки. Открывается как обычная страница: `index.html`.
Локальный запуск: `python3 -m http.server` в этой папке, затем http://localhost:8000

## Что менять клиентке
Всё в одном файле `js/products.js`:
- `SHOP`: название, телефон, e-mail, ссылки на Telegram / WhatsApp, порог бесплатной доставки, стоимость доставки;
- `PRODUCTS`: названия и цены (цены сейчас ориентировочные, замените на свои);
- `COLLECTIONS`: коллекции.

Заказы: при оформлении сохраняются в браузере (localStorage). Чтобы заказы приходили вам,
укажите `orderWebhook` (URL формы/сервера, получит JSON) или используйте кнопки Telegram / WhatsApp на финальном экране.
Онлайн-оплата не подключена: для неё нужен платёжный провайдер (ЮKassa, CloudPayments и т.п.).

## Структура
- `index.html`: разметка страницы
- `css/style.css`: стили, 3D и анимации
- `js/app.js`: каталог, фильтры, корзина, оформление, 3D-эффекты
- `assets/`: изображения из материалов производителя (прибор, картриджи, серьги, шаги инструкции, сертификаты)
